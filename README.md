# Ghost in the Heart

A visual novel developed using the Ren'Py engine.

> [!WARNING]
> **Language Notice:** The game is currently only available in French.
>
> **Content Warning:** This story deals with sensitive themes, including suicide, murder, depression, and a heavy presence of androids.

## How to Run the Game

Depending on your operating system and environment, three methods are available:

### 1. Windows

Double-click the executable file directly:
* `Ghost_in_the_Heart.exe`

*Note: If Windows SmartScreen blocks execution on the first launch, click "More info" and select "Run anyway".*

### 2. Linux and macOS (Shell Script)

The script automatically detects your system architecture and loads the appropriate libraries.

1. Open a terminal inside the game directory.
2. Make the script executable:
```bash
chmod +x Ghost_in_the_Heart.sh

```

3. Start the game:

```bash
./Ghost_in_the_Heart.sh

```

### 3. Python (Cross-platform)

If you already have Python 3 installed on your system:

```bash
python3 Ghost_in_the_Heart.py

```

## Save File Locations

Saved games are handled by Ren'Py and stored in your operating system's user directory:

* Windows: `%APPDATA%/RenPy/Ghost_in_the_Heart/`
* Linux: `~/.renpy/Ghost_in_the_Heart/`
* macOS: `~/Library/RenPy/Ghost_in_the_Heart/`
